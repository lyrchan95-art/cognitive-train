# Admin Portal User Guide

## Goal
Add a clear, role-aware instruction guide inside the Admin Portal so administrators, content editors, and data scientists can confidently complete their work.

## Build
- Add a dedicated `/admin/guide` page and a persistent **Guide** tab in the admin navigation.
- Organize instructions by role and workspace: portal access, content publishing, archetype cards, pathways, research, Content Console, Behaviour Lab, governance, exports, and troubleshooting.
- Include concise numbered workflows, permission labels, safety notes, and direct links to the relevant admin screens.
- Keep the page aligned with the existing paper/ink visual system and usable at 360px mobile width.
- Add unique page metadata and preserve current role-based access controls.

## Validation
- Confirm navigation and guide links resolve correctly.
- Check desktop and mobile layouts in the running preview.
- Confirm the project passes its automated build and type checks.
